# 手动生成对照记录

本记录用于用户在外部图像工具中生成和判断结果。项目脚本只生成提示词与记录模板，不上传图片、不调用图像模型，也不自动判断“像不像”。

## 每轮固定条件

记录：目标 Profile ID 和修订时间、编译器版本、模型/版本、语言、采样设置、分辨率、是否支持种子、种子或运行 ID、生成日期。视角信息只作为内部评测条件，不写入生成提示词。

## 最小对照

同一份经用户核对的 Profile 建立两种编译结果：当前稳定编译器与优化编译器。每种结果在同一外部工具中生成多个候选，尽量固定模型和设置。一次只改变一个主要因素。

逐候选记录：

- 上唇：唇红高度、轮廓、丰满度或外突是否符合、无法判断；
- 眉眼：眉弓外观、眉毛走向/密度、眼裂和眼睑是否符合、无法判断；
- 整体：脸型、颧部、下颌、五官相对位置是否符合、无法判断；
- 目标整体相似度：用户选择 A、B、都不像或无法判断；
- 失败原因：观察错误、提示词遗漏、模型未执行、光照/姿态差异、其他。

不要只保存最优图片；记录全部候选及失败项。用户的视觉判断是本轮验收依据，自动图像相似度只能作为后续辅助指标，不能替代判断。

可用 `python scripts/create_generation_record.py PROFILE.json --out RECORD.json` 创建空白记录。
